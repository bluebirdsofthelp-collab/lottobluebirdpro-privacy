앱 이용 중 오류, 기능 관련 문의, 개선 제안 등이 있는 경우 아래 고객지원 채널을 이용해 주세요.

GitHub 문의 페이지:

https://github.com/bluebirdsofthelp-collab/lottobluebirdpro-privacy/issues

- 사용 중인 iPhone 모델
- iOS 버전
- 로또블루버드Pro 앱 버전
- 문제가 발생한 기능
- 발생한 현상 또는 오류 내용

## 앱 이용 안내

로또블루버드Pro는 로또 6/45 번호 분석과 조합 관리를 위한 프리미엄 분석 도구입니다.

- 광고 없음
- 월간·연간 구독 없음
- 정기결제 없음
- 회원가입 없음
- 로그인 없음
- 앱 내부 복권 구매 기능 없음
- 앱 내부 복권 구매대금 결제 기능 없음

로또블루버드Pro는 복권 당첨을 보장하거나 미래의 당첨번호를 확정적으로 예측하는 서비스가 아닙니다.

앱에서 제공하는 분석, 제외수, 필터, 추천 점수 및 시뮬레이션 결과는 번호 선택을 돕기 위한 참고 정보입니다.
